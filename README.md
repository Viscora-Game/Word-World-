## 🌟 Öne Çıkan Özellikler

- **8 Büyük Keşif Dünyası & 32 Alt Kategori:**
  1. ⚽ **Spor Dünyası:** 20 Efsane İlk 11 taktik sahası, futbol efsaneleri, NBA ve Formula 1
  2. 🎬 **Dizi & Sinema:** Kült başyapıtlar, unutulmaz diziler, usta yönetmenler ve Oscar tarihi
  3. 🏛️ **Genel Kültür & Tarih:** Antik medeniyetler, tarihi liderler, dönüm noktası savaşlar ve buluşlar
  4. 🔬 **Bilim & Evren:** Bilim insanları, DNA & genetik, derin uzay ve kuantum fiziği
  5. 🌎 **Coğrafya & Dünya:** Sıra dışı başkentler, dünya harikaları, yüce dağlar ve nehirler
  6. 🦁 **Hayvanlar & Doğa:** Vahşi yaşam, okyanus canlıları, gökyüzünün kuşları ve botanik
  7. 🎤 **Müzik Dünyası:** Efsane sanatçılar, rock grupları, müzik türleri ve enstrüman tarihi
  8. 🍕 **Dünya Mutfağı:** Türk lezzetleri, Avrupa klasikleri, sokak lezzetleri ve tatlılar
- **275+ Zengin Seviye:** Her seviyede kültürel, bilimsel veya taktiksel bilgi kartları.
- **Taktiksel İlk 11 Sahası:** Sahadaki futbolcu dizilişine bakarak takımı tahmin etme modu.
- **Tam Türkçe Karakter Desteği:** `Ç, Ğ, İ, Ö, Ş, Ü` harfleri ve büyük `İ / I` toleranslı eşleme.
- **Mobil Öncelikli & Sıfır Kaydırma:** Her ekran boyutuna otomatik uyum sağlayan ve ekranı taşırmayan dinamik oyun tahtası.
- **Anti-Exploit Oyun Mekaniği:** Elenildiğinde kelime gizli kalır; oyuncunun pes etmeyip hafızasını kullanarak tekrar denemesi gerekir.
- **Günlük Görev & Haftalık Liderlik Tablosu:** Her gün yeni gizemli kelime ve lig sıralaması.

## 🚀 Yerel Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için:

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirici sunucusunu başlatın
npm run dev

# 3. Tarayıcınızda açın:
# http://localhost:5173
```

Canlı yayın için derleme (Production Build):
```bash
npm run build
```

## 🛠️ Teknoloji Yığını

- **Framework:** React 19 + Vite
- **Stil & Tasarım:** Tailwind CSS v4 (3D casual game derinlikleri, gradientler ve mikro-etkileşimler)
- **İkonlar:** Lucide React & Özel 3D Oyun Varlıkları
- **Efektler & Ses:** Canvas-Confetti, Web Audio API Sound Synthesizer
